# Customer Analytics: Preparing Data for Machine Learning

## Project Overview
This project focuses on cleaning and optimizing a large customer dataset for **Training Data Ltd.**[span_1](start_span)[span_1](end_span) The dataset contains anonymized student information used to build predictive models that determine whether students are looking for a new job[span_2](start_span)[span_2](end_span). 

By optimizing dataset storage structures and data types, this project builds a proof-of-concept that reduces memory overhead and decreases overall machine learning model training times without sacrificing dataset size[span_3](start_span)[span_3](end_span).

## Key Features
* **Memory & Storage Optimization:** Converts raw data into memory-efficient data types to improve computational performance[span_4](start_span)[span_4](end_span).
* **Data Cleaning & Pipeline:** Handles missing values and normalizes features derived from `customer_train.csv`[span_5](start_span)[span_5](end_span).
* **Predictive Readiness:** Prepares student profile data (e.g., location, development index) for job-seeking classification models[span_6](start_span)[span_6](end_span).

## Dataset Summary
The project utilizes `customer_train.csv` containing anonymized student profiles with key fields including[span_7](start_span)[span_7](end_span):
* `student_id`: Unique identifier for each student[span_8](start_span)[span_8](end_span).
* `city`: City code representing student location[span_9](start_span)[span_9](end_span).
* `city_development_index`: Scaled development index for the student's city[span_10](start_span)[span_10](end_span).
